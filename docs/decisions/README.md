# Decisions

Architecture decision records for this repo. Filename pattern: `NNNN-title.md` (four-digit id, kebab title).

This is the canonical ADR directory (`docs/decisions/`). If `docs/adr/` or `docs/DECISIONS/` exists, it is a stub that points here.

Fleet-level law lives in GromCodebase `docs/decisions/` and `docs/fleet/` — do not copy those indexes into this folder.
